# Phase 0 Guide — Data Foundations & Engine Core

**Objective:** three-tier data architecture (raw → normalized → features), the
engine package (fills, calendar, structures), and the Sep-1 quota spend —
without breaking anything that exists.

---

## 1. Build order

0. Public GitHub repo + hygiene tooling (§10) — before new code accumulates,
   so nothing ever exists only on this disk.
1. `engine/paths.py` + package skeleton (nothing else imports hardcoded paths
   after this).
2. `engine/fills.py`, `engine/calendar.py`, `engine/structures.py` (pure
   logic, no I/O — testable immediately).
3. Tier-1 fetch wrapper + per-source adapters (`engine/data/`).
4. Tier-2 schemas + normalizers + validation battery.
5. `rebuild.py` + migration test against the existing master panel.
6. Coverage/audit report; then, and only then, the Sep-1 pull scripts.

Rationale: 1–2 unblock Phase 1/2 design review; 3–5 must be proven on cached
data before any quota is spent; 6 tells us exactly what to pull.

## 2. Architecture

```
engine/
  __init__.py
  paths.py            # logical name -> physical path registry
  fills.py            # FillModel
  calendar.py         # earnings calendar (canonical)
  structures.py       # trade structures -> leg lists
  data/
    __init__.py
    fetch.py          # Tier-1 wrapper: fetch(source, endpoint, params)
    throttle.py       # per-source pacing/backoff/quota guard
    sources/
      orats.py        # requests + ?token=, timeout>=120s, quota headers
      polygon.py      # subprocess curl (urllib 401 gotcha), 6.5s gate
      oquants.py      # playwright cookie->token dance, token reuse per process
      yf.py           # yfinance, disk-cached
    schemas.py        # Tier-2 column specs + assert_schema(df, name)
    normalize/
      n_securities.py  n_events.py  n_daily.py  n_chains.py  n_trades.py
    validate.py       # sanity battery + quarantine flags
    rebuild.py        # tier1 -> tier2 -> tier3 orchestrator
data/
  raw/fetch/{source}/{k[:2]}/{key}.body.gz + {key}.meta.json   # NEW raw store
  raw/quarantine/     # flag files only; raw bodies never move
  curated/{table}/year=YYYY/*.parquet     # Tier 2 (csv.gz fallback)
  features/           # Tier 3, versioned by snapshot hash
  MANIFEST.md         # GENERATED by rebuild.py
checks/phase0_checks.py
```

### paths.py
Single dict of logical→physical paths. Grandfathered raw stays where it is:
`RAW_ORATS = earnings_predictions/data/raw/orats`, `RAW_OQUANTS = .../oquants`,
`RAW_YF = .../yfinance`, `RAW_POLYGON_LEGACY = polygon_cache/`, plus
`LEGACY_PANEL = .../data/processed/events_with_orats_sum.csv`, etc. **Never
move or rename these directories.** New tiers live under
`/root/investing-plan/data/`.

### fetch.py contract
```python
def fetch(source, endpoint, params, *, live=False, timeout=120) -> RawRecord
# RawRecord: .body (bytes), .meta (dict), .path, .from_cache (bool)
```
- Cache key = sha256 of canonical JSON `{source, endpoint, sorted(params)}`;
  `live=True` appends today's date to the key (historical endpoints are
  immutable → cached forever; live endpoints get one entry per day).
- Cache hit → zero network. Miss → `throttle.acquire(source)` → request →
  persist body verbatim (gzip) + meta (url, ts, status, quota headers, bytes)
  → append one row to `data/raw/fetch/fetch_log.csv` → return.
- Non-2xx: persist NOTHING to the main store (log only), raise. 401/login
  redirect → raise `CredentialRotated` and STOP (tell the user; never retry-loop).
- Throttle config: polygon price/aggs 6.5s gate + 65s backoff on 429 (6
  retries); orats 0.3s pacing; oquants 0.5s. Polygon adapter shells out to
  curl; keep ONE polygon-touching process at a time (lockfile in
  `data/raw/fetch/.polygon.lock`).
- **Quota guard (ORATS):** adapter parses `X-Monthly-Quota-Remaining`; refuse
  new calls when remaining < 3,000 (live-ops reserve) unless
  `ORATS_ALLOW_RESERVE=1`. Every call appends to the existing
  `quota_log.csv`.

### fills.py
```python
class FillModel:            # alpha in [0,1]
    def buy(self, bid, ask):  return ask - alpha*(ask-bid)
    def sell(self, bid, ask): return bid + alpha*(ask-bid)
WORST, MID, BEST = FillModel(0), FillModel(0.5), FillModel(1)
```
Guard: if bid > ask or bid < 0 → raise (bad chain row reached pricing;
validation should have caught it upstream). Missing/zero bid with positive ask
is a real market state — price it, but flag `wide_market=True` when
(ask−bid)/mid > 0.5.

### calendar.py
Canonical forward + historical calendar from ORATS `hist/earnings`
(`anncTod` → session: <1200 = BMO else AMC), cross-checked against the
oquants panel dates; disagreement → `date_agree=False` flag, ORATS wins
(EXP-038: 99.52% agreement, anncTod authoritative). Detects date CHANGES
between refreshes and emits a flag list (stale dates are a known loss source).

### structures.py
Each structure returns legs: `[(right, strike_rule, expiry_rule, side, qty)]`
plus entry/exit day rules. Implement: `put_calendar` (short front put ~1 DTE +
long back put, back-DTE parameter, SAME open and close timestamps for both
legs), `straddle_through`, `straddle_runup`. Pricing of a structure = sum of
legs priced from a chain snapshot through a FillModel — this is the ONE
pricing path every phase uses.

## 3. Tier-2 schemas (define in schemas.py; enforce with assert_schema)

- `securities`: ticker, first_date, last_date, mcap_usd, mcap_log_norm, src.
- `earnings_events`: event_id (ticker+date), ticker, event_date, session
  (BMO/AMC), annc_tod, src_orats, src_oquants, date_agree.
- `daily_market`: ticker, date, spot, iv10, iv30, exern_iv30, implied_move,
  implied_reconstructed (bool), rvol30, skew, contango, fwd90_30, mcap_log,
  src columns for audited fields.
- `option_chains`: ticker, obs_date, expiry, dte, strike, right, bid, ask,
  mid, iv, delta, spot, src_file.
- `trades`: trade_id, kind (sim/paper/live), strategy, variant, ticker,
  event_id, legs (json), entry_date, exit_date, fill_alpha, entry_cost,
  exit_value, ret, provenance.

**Unit/convention traps — fixed here, once (normalize/, not consumers):**
1. ORATS `mktCap`: millions before 2026-03-11, thousands after → normalize to
   `mcap_usd`, keep the era-normalized log (existing convention).
2. Realized-move convention: BMO = close(t−1)→close(t), AMC = close(t)→close(t+1).
3. oquants implied moves before 2022 → `implied_reconstructed=True`.
4. ORATS strikes file format: `{entry_date, tickers, rows:[...]}` with
   `*_t14_b{N}` batch naming and `.done*` markers — the chain normalizer must
   parse all existing kinds (S2 entry, post-print exit, T−14).
5. Source priority on conflict: chains→ORATS; realized moves→oquants panel
   (OHLCV-validated); calendar→ORATS anncTod; spot→ORATS, cross-checked yfinance.

## 4. validate.py — ingestion battery

Run on every normalizer output before it lands in curated/:
- spot vs yfinance close: |diff| ≤ 1.3% (known tolerance) on a 2% sample;
- chain straddle mids vs Polygon where overlap exists (2024-08+): ratio
  within ±3%;
- schema: required columns, dtypes, no dupe keys, dates monotone per
  partition, bid ≤ ask, dte = expiry − obs_date;
- failure → write a flag file to `data/raw/quarantine/` naming the raw
  source file + reason, EXCLUDE those rows from Tier 2, print loudly. Raw is
  always kept; nothing is silently dropped.

## 5. rebuild.py and the migration test

`python3 -m engine.data.rebuild [--sample N] [--table T]` rebuilds Tier 2 from
Tier 1 from scratch, then Tier 3 (the causal panel, ported from the existing
build logic in `earnings_predictions/src/`). Idempotent; per-table progress
lines; writes MANIFEST.md (tables, rows, year coverage, source files, hashes)
and a snapshot hash (sha256 over table content hashes) into
`data/features/SNAPSHOT`.

**Migration test (`checks/phase0_migration.py`):** join new panel to
`LEGACY_PANEL` on (ticker, event_date); assert row counts by year match
(document any legitimate delta, e.g. quarantined rows), moves match to
0.01pp, implied/IV fields to 0.1, mcap_log to 0.01. Output a reconciliation
report (Phase 4 format once available; markdown table before that). **The
plan's verdicts rest on the legacy panel — a silent numeric change here
invalidates everything downstream. Do not proceed past a red migration test.**

## 6. Sep-1 pull plan (`engine/data/pulls/sep2026_plan.py`)

- Enumerate target events (2017–2026, mcap ≥ $1B slices) missing T−1, T−14,
  or post-print chains, put-side included; group by trade date (one strikes
  call = one date, many tickers) to minimize calls.
- `--dry-run` prints: #calls, quota cost, coverage gained, per-day batches.
  Spending requires `--confirm`. Budget ≤16k calls; reserve 3k stays.
- Resumable (`.done` markers per date, existing pattern), flush per file,
  progress ≥1/min, single process.

## 7. Constraints (hard rules)

- Tier 1 append-only; Tier 2 rebuildable from Tier 1 with NO network access
  in normalizers; Tier 3 rebuildable from Tier 2.
- Never modify grandfathered dirs; never re-download cached data.
- One Polygon process; ORATS reserve floor; credentials never printed.
- Everything downstream (Phases 1–6) reads Tier 2/3 through `engine.paths` —
  direct reads of raw source formats outside `normalize/` are a code smell.

## 8. Acceptance tests (`checks/phase0_checks.py`)

1. **Cache-first:** same fetch twice → second is `from_cache=True`, zero
   network (assert via fetch_log row count).
2. **Throttle:** two consecutive polygon fetch misses are ≥6.5s apart.
3. **Resume:** kill a sample pull mid-run, restart → no duplicate rows, no
   re-fetched keys.
4. **Determinism:** `rebuild --sample 20` twice → frame-equal Tier-2 tables.
5. **Migration:** §5 test green on the FULL panel.
6. **Poison:** corrupt a copy of one raw file → normalizer quarantines it,
   Tier 2 lands without it, flag file exists.
7. **Structures:** put_calendar/straddle payoffs hand-checked on 3 known
   events against manually computed leg P&L from cached chains.
8. **FillModel:** WORST/MID/BEST reproduce a known EXP-048 trade's three
   published returns.
9. **Coverage report** renders: events × year × mcap × chain-availability
   heatmap; put vs call coverage.

## 9. Failure modes

- Quota exhausted mid-pull → guard stops cleanly; plan resumes next month.
- Credential rotation → `CredentialRotated`, stop, tell the user.
- pyarrow uninstallable → csv.gz fallback (schemas.py handles both; slower,
  same contracts).
- Host sleeps mid-job (WSL2) → resumability covers it; never assume a
  background job survived, check its output.

## 10. Public GitHub repo & hygiene (build FIRST)

**Split:** PUBLIC repo = code + build docs (`engine/`, `checks/`, `guides/`,
`experiments/*/spec.yaml` + `run.py`, dashboard code, the master plan,
`.env.example` with variable NAMES only, `RECOVERY.md`). PRIVATE mirror =
irreplaceable non-code artifacts (`ledger/`, reports, research findings docs
like HANDOFF/VERDICTs, `config/thesis/`). NOWHERE = secrets and market data
(data is re-pullable at quota cost; 57k files don't belong in git).

**User tasks (agent cannot do these):** create the public repo and the
private mirror repo on GitHub; authenticate with `! gh auth login` in the
session. Agent then: `git init`, configure user.name/user.email, wire
remotes, first push after hygiene passes.

**Allowlist `.gitignore` sketch** (default-deny; later rules win, so hard
blocks come LAST and override the allows):

After writing it, verify with `git status --ignored` and review the FULL
`git ls-files` output line by line before the first push — the first push is
the one that matters; public history is forever.

**`checks/repo_hygiene.py`** (also installed as `.git/hooks/pre-commit`):
1. Reads `.env` at runtime and greps every staged blob for the current
   secret VALUES (the strongest possible check — catches a key pasted into
   any file type).
2. Blocks staged data extensions (csv, parquet, gz, jsonl, sqlite) and any
   staged file >1 MB.
3. Blocks staged paths under the data/ledger/results dirs (defense in depth
   behind the gitignore).
Exit nonzero → commit blocked. No `--no-verify` habit: if the hook is wrong,
fix the hook.

**Cadence:** commit + push at every green acceptance milestone and end of
session. The Phase 3 nightly job also pushes code and syncs the private
mirror (ledger/reports/findings/thesis) — so a dead laptop loses at most one
day of ledger.

**`RECOVERY.md`** (in the public repo): fresh-machine restore path — clone
public repo; install Python deps (list them); restore `.env` from the
password manager (never from any repo); clone the private mirror to restore
ledger/reports/thesis; re-pull market data via the Phase 0 pull scripts
(quota-budgeted, resumable); run `checks/` to verify the restore.

**Acceptance tests (extend `checks/phase0_checks.py`):**
10. **Hygiene poison:** stage (a) a file containing a real `.env` value,
    (b) a small .csv, (c) a 2 MB file → each individually blocks the commit.
11. **Recovery drill:** clone the public repo into a temp dir → no secrets
    or data present (`grep` + extension scan), `engine` imports cleanly, and
    the no-data subset of checks passes; RECOVERY.md steps read true.
